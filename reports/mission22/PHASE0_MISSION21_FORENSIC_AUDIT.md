## 1. Executive Forensic Summary

Phase 0 conducted an exhaustive, independent forensic audit of the experimental code, sample pairing mechanics, ground-truth label assignments, and statistical calculations in Mission 21.

### Primary Audit Findings:
1. **Asynchronous Constructed Pairings (Not Simultaneous Observations):**  
   The 450 reported multi-modal trials were **not** 450 independent, simultaneous video-audio recordings. They were synthetic scenario combinations generated by pairing 160 frozen visual frames from WeatherGuard with audio recordings from Rescue Drone V2.
2. **Extensive Sample Recycling:**  
   The 160 available test frames were evaluated an average of **2.81 times each** across the 9 scenarios (ranging up to 5 repetitions for individual frames). Specifically, the 47 frames of `dawn_snow` were reused identically across four separate scenarios (`Daylight_Clear`, `Low_Visual_Resolution`, `Strong_Wind`, and `Drone_Rotor_Noise`). Similarly, in specialized noise subsets with only 9 negative audio clips (such as `drone_propeller`), individual clips were repeated up to 3 times in a single scenario.
3. **The "Phantom Person" Ground-Truth Defect:**  
   In 143 out of 315 positive trials (**45.4%**), ground truth was forced to `True` because an audio distress clip was attached, even though the paired visual frame contained **zero visible persons**. Because the image was empty of human victims, the Vision-Only detector predictably reported no detection. This was scored as a **False Negative (miss)** against Vision-Only. In fact, **143 out of the 208 reported Vision-Only misses (68.75%)** were phantom-person artifacts where no person existed to be detected. This artificially depressed Vision-Only recall to 33.97% and exaggerated the perceived recall gain of multi-modal fusion.
4. **The "Silent Victim" Ground-Truth Defect for Audio:**  
   Conversely, in 86 trials (27.3% of positives), an image containing a visible pedestrian was paired with non-distress speech audio, with ground truth set to `True`. Because no distress cry occurred, the Audio-Only detector predictably reported negative, and was penalized as a False Negative (miss).
5. **Threshold Tuning on the Test Set:**  
   The operational audio threshold ($\tau^* = 0.54$) was determined in Mission 20 by sweeping thresholds directly on the locked test split (`eval_ds`). This represents test-set leakage, invalidating the claim of completely uncalibrated zero-shot generalization.
6. **Statistical Inflations (Cohen's d and p-values):**  
   The reported Cohen's $d = 3.436$ was calculated on the distribution of bootstrap resampled F1 values rather than on per-trial independent observations. Because bootstrap standard deviation diminishes with sample size ($1/\sqrt{N}$), the resulting ratio was a bootstrap z-score, not an effect size. Furthermore, bootstrap resampling was performed on only **4 underlying video/domain sequences**, severely violating cluster-count assumptions.

## 3. Forensic Analysis of Ground-Truth Assignments

In `scripts/mission21/run_multimodal_controlled_experiments.py`, the pairing and ground-truth assignment logic was implemented as:

```python
if idx % 2 == 0 and pos_auds:
    aud_sample = pos_auds[idx % len(pos_auds)]
    ground_truth = True  # Distress vocalization present
elif neg_auds:
    aud_sample = neg_auds[idx % len(neg_auds)]
    ground_truth = gt_person  # Only target if visually confirmed person present
```

### Forensic Breakdown of the 450 Trials:
- **Total Ground-Truth Negative Trials:** 135 trials (30.0%)
- **Total Ground-Truth Positive Trials:** 315 trials (70.0%)
  - **Truly Bimodal Positive (Person Visible + Distress Cry):** Exactly **86 trials (27.3% of positives)**.
  - **Phantom-Person Trials (gt=True, Distress Cry Present, NO Person Visible):** **143 trials (45.4% of positives)**.
  - **Silent-Person Trials (gt=True, Person Visible, NO Distress Cry):** **86 trials (27.3% of positives)**.

### Scientific Implications of Phantom-Person Scoring:
When evaluating Vision-Only against this composite ground truth:
- Vision-Only detected a person on 107 trials ($TP = 107$).
- Vision-Only reported no person on 208 positive trials ($FN = 208$).
- However, **143 of those 208 False Negatives had no visible human in the image!**
- The true vision miss rate on frames *actually containing a person* was:
  $$\text{Actual Vision Miss Rate} = \frac{208 - 143}{315 - 143} = \frac{65}{172} = 37.79\%$$
  rather than the reported **66.03%**.
- By declaring a visual frame a "failure" because it failed to detect a victim who was only present as an audio clip, the baseline for Vision-Only was artificially crippled.

## 4. Forensic Analysis of Threshold Tuning & Leakage

In Mission 20 (`scripts/kaggle/audio_gpu_runner.py`), the optimal decision threshold $\tau^* = 0.54$ was derived using:
```python
# audio_gpu_runner.py lines 192-205
best_tau = 0.50
best_f1 = 0.0
for tau in np.arange(0.1, 0.9, 0.02):
    ...
    if f1 > best_f1:
        best_f1 = f1
        best_tau = tau
```
This loop evaluated `eval_ds`, which was mapped directly to `split="test"`. Consequently:
1. The 0.54 threshold was optimized on the locked test data.
2. In Mission 21, `calibrated_threshold = 0.54` was hardcoded into `AcousticEvidence`.
3. Evaluating test set performance using a threshold selected on that same test set violates strict split isolation and produces an optimistic bias.
4. **Remedy:** Thresholds must be calibrated exclusively on the training and validation splits.

## 5. Forensic Analysis of Statistical Claims

### 5.1 Cohen's d Inflation
Mission 21 reported `Cohen's d = 3.436` for Adaptive Fusion vs. Vision-Only.
Forensic audit of `scripts/mission21/run_ablation_and_statistical_evaluation.py` reveals:
```python
paired_diffs_vs_vision.append(boot_f1s["adaptive_fusion"] - boot_f1s["vision_only"])
...
def cohens_d(diffs):
    mean_diff = np.mean(diffs)
    std_diff = np.std(diffs, ddof=1)
    return round(float(mean_diff / (std_diff + 1e-8)), 3)
```
- `diffs` is an array of **500 bootstrap F1 differences**, not 450 per-sample observation deltas.
- Because the standard deviation of bootstrap sample means scales as $O(1/\sqrt{N})$, `np.std(diffs)` was artificially small ($0.111$).
- Dividing the mean F1 difference ($0.3816$) by the bootstrap sample variance yielded $3.436$.
- This represents a bootstrap z-score, **not Cohen's $d$**. Cohen's $d$ must be calculated on independent sample-level or cluster-level effect differences.

### 5.2 Invalid $p < 0.001$ Assertion
Mission 21 asserted:
```python
"significant_at_001": bool(np.percentile(paired_diffs_vs_vision, 2.5) > 0.0)
```
- A 95% confidence interval has $\alpha = 0.05$ (two-tailed). The fact that the 2.5th percentile is strictly greater than zero establishes significance at **$p < 0.05$**, not $p < 0.001$.
- Labeling this `significant_at_001` was statistically unfounded.
- Furthermore, because the entire dataset was partitioned across only 4 visual sequences, cluster resampling with $K=4$ violates standard asymptotic assumptions ($K \ge 30-50$).
